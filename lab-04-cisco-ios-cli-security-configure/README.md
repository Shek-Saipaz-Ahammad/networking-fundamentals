# 🧪 Lab 04 - Cisco IOS CLI Configuration

## 🎯 Objective

Practice basic Cisco IOS CLI configuration by changing device settings, configuring passwords, and saving the device configuration.

---

## 🛠️ Tools Used

- Cisco Packet Tracer
- Cisco IOS CLI

---

## 📌 Tasks Performed

- Changed the hostname of the router and switch.
- Configured an `enable password`.
- Tested access to Privileged EXEC mode.
- Viewed the running configuration.
- Enabled password encryption.
- Configured an `enable secret`.
- Compared encrypted passwords in the configuration.
- Identified the encryption types used.
- Saved the running configuration to the startup configuration.

---

## 📖 Key Learning

- Navigated different Cisco IOS CLI modes.
- Configured basic device settings.
- Learned the difference between `enable password` and `enable secret`.
- Understood the purpose of password encryption.
- Practiced saving device configurations.
- Used the `no` command to remove configurations.
